# Pesu

**பேசு — "speak".** Learn real-life phrases in Spanish, French, German, Japanese and Hindi.

Live: https://pesu.vercel.app (see the repo's About for the current URL)

- 7 illustrated scenes × 8 phrases: Essentials, Conversation, Numbers, Colours, Restaurant, Getting around, In case of trouble.
- Learn: audio at normal and slow speed, tap any word to hear it, and **Say it** speech recognition with a match score.
- Test: listen and pick the picture, pick the phrase, build the sentence from tiles, type what you hear (with accent keys), match pairs. Missed items come back in the same session until they are right.
- **Super Memory:** Leitner spaced repetition (10 min, 1, 3, 7, 21 days).
- XP, daily goal ring, streak, keyboard shortcuts, light and dark mode. Progress stays on the device.

Audio and speech recognition use the browser's Web Speech API, so voices depend on the device. Method inspired by Loecsen.

## Run locally

It's one static file: serve the folder (`python3 -m http.server`) and open `index.html`.
